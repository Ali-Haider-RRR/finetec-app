# Fine Tec Invoices

Offline invoice app (installable PWA) for Fine Tec. Create invoices in five designs, add a signature,
share or download as PDF / image, search history, manage customers. No server — everything is stored on the device.

## Use
1. Open the site once with internet, then "Add to Home Screen" (Android Chrome: menu → Install app).
2. After that it works fully offline.
3. Settings → **Backup** regularly (invoices live only on the device).

## Deploy (GitHub Pages)
Settings → Pages → Deploy from a branch → `main` / `(root)`.
